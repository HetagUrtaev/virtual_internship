# Pereval API

REST API для работы с данными о горных перевалах. Проект демонстрирует работу с Django REST Framework, включая создание, редактирование и фильтрацию объектов с правилами валидации.
___
## Задача

Реализовать REST API для управления записями о горных перевалах со следующими требованиями:

* создание новых записей о перевалах;
* редактирование существующих записей (с ограничениями);
* получение списка объектов (в т.ч. фильтрация по email пользователя);
* получение отдельной записи по ID;
* соблюдение правил при редактировании данных.
___


## Как использовать

**Описание:** добавляет новый перевал в базу данных. Все поля в `user` обязательны.

**Метод:** `POST`
**URL:** `/submitData/`
**Content‑Type:** `application/json`

## Реализованные функции

**1. Создание объектов (`POST /submitData/`)**
* принимает JSON с данными о перевале и пользователе;
* возвращает ID созданного объекта.

**2. Получение данных**
* список всех объектов (`GET /submitData/`);
* отдельный объект по ID (`GET /submitData/<id>/`).

**3. Редактирование (`PATCH /submitData/<id>/`)**
* доступно только для объектов со статусом `new`;
* запрещено изменять персональные данные пользователя (ФИО, email, телефон);
* запрещено удалять данные о пользователе;
* запрещено менять статус объекта.

**4. Получение данных по email пользователя**

`GET /submitData/?user__email=<email>`

**5. Документация API**

* `/api/schema/` — OpenAPI‑схема (JSON)
* `/api/docs/` — интерактивная документация (Swagger UI)

**6. Бизнес‑правила**
* при создании все обязательные поля должны быть заполнены;
* статус объекта задаётся автоматически;
* фильтрация доступна всем пользователям.

## Установка и запуск

### Предварительные требования 
* Python 3.10+
* pip
* virtualenv (рекомендуется)
* SQLite (по умолчанию) или PostgreSQL

### Необходимые библиотеки
Полный список зависимостей смотрите в файле `requirements.txt`. Ключевые библиотеки:
* Django 6.0.4
* djangorestframework 3.17.1
* psycopg2-binary 2.9.11 (для PostgreSQL)

### Шаги установки

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/HetagUrtaev/virtual_internship
python -m venv venv
venv\Scripts\activate
cd project_internship
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

```
